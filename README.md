# Color-the-ducts

> [!NOTE]
> 若有反馈，请发送反馈到bugsoc@qq.com / If you have any feedback, please send it to bugsoc@qq.com

## 中文

> 直接看导管颜色，就知道里面运输的是什么液体。

Color-the-ducts 是一个 Mindustry 客户端显示增强模组。它把导管中正在运输的液体用颜色标出来，让你沿着一条复杂管线检查生产、供给和堵塞时，不必逐段打开信息面板确认。

它只改变本地显示，不修改物流逻辑，服务器也不需要安装。适合大型工厂、多人服务器和需要快速检查液体网络的玩家。

### 安装

将 dist/color-the-ducts.zip 或 dist/color-the-ducts.jar 放入 Mindustry 的 mods 目录并启用。Release 中的合并包同时支持桌面端和 Android。

### 构建

~~~powershell
.\gradlew.bat clean deploy
~~~

## English

> Know what a liquid duct carries by looking at its color.

Color-the-ducts is a Mindustry client-side display mod. It colors the center of active liquid ducts, making complex production and supply lines easier to inspect without opening an information panel for every segment.

It changes presentation only, does not alter logistics behavior, and requires no server installation. It is useful for large factories, multiplayer servers, and anyone who needs to inspect liquid networks quickly.

### Install

Put dist/color-the-ducts.zip or dist/color-the-ducts.jar in Mindustry's mods directory and enable it. The merged Release package supports both desktop and Android.

### Build

~~~powershell
.\gradlew.bat clean deploy
~~~
